# Changelog

All notable changes to UniJam will be documented here. This project follows
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-07-15

### Added

- Cross-browser room event log and authoritative snapshots
- Capability-protected host and guest room protocol
- Participant-scoped sessions and heartbeat presence
- Fair queueing, suggestions, approvals, voting, reactions, and handoffs
- Provider-aware matching and publishing domain engines
- Atomic rate limits and replay-safe mutations
- Forty-two domain and security tests plus rendered-product validation
- Open-source documentation, contribution policies, and CI
